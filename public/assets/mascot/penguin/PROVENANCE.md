# Modern penguin mascot asset pack

- Identity reference: `penguin-reference.png`, supplied by the user.
- Logo and pose key art: generated with the built-in image generation route using the supplied reference and the approved modern penguin logo as identity anchors.
- Identity invariants: round compact body, three-feather tuft, large oval eyes, cream face patches, blush cheeks, amber beak and feet, deep-plum body, coral neckerchief.
- Palette direction: deep plum, mint, coral, amber and warm cream.
- Transparent pose PNGs: extracted from flat magenta chroma-key sources with the installed ImageGen background-removal helper.
- GIFs: deterministic 24-frame, 640 × 640, infinitely looping exports built by `scripts/build_penguin_gifs.py`.
- Motion: hello uses a friendly side-to-side wave rhythm; study uses a calm breathing/listening pulse; success uses a buoyant jump loop.
